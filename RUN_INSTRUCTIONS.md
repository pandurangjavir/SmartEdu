# How to Run SmartEdu

This project requires two separate terminals to run simultaneously: one for the Python Backend and one for the React Frontend.

## 1. Start the Backend
Open a new terminal window and run:
```bash
cd c:\smartEdu\backend
..\.venv\Scripts\python.exe app.py
```
*The backend API will start running on http://127.0.0.1:5000*

## 2. Start the Frontend
Open a **second** terminal window and run:
```bash
cd c:\smartEdu\frontend
npm run dev
```
*The React application will start running on http://localhost:3000*
